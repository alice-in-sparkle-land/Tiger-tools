SQL Doc Builder

Turn a SQL project folder into documentation your team can read.

Point it at your project folder and it drafts the documentation for you: how the pipeline runs, data flow, table catalog, column logic, script-by-script notes and a list of things to review. You add the "why" in plain words, then export a Markdown file or a single HTML page.

Drop your project folder here

Reads .sql, .hql, .txt, .py and .md files

Everything runs inside this page. Your files are never uploaded and the page makes no network requests, so it also works offline. Your notes are saved in this browser; use Export notes to keep a backup file.
